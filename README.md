# Bible Reader content — PT-Portuguese

This repository contains the Bible Reader SD-card content for **PT-Portuguese**.

## Directory layout

- `text/PT-Portuguese/` — all Bible translations and their original nested folder structure.
- `audio/PT-Portuguese/` — audio Bible book folders and chapter MP3s.
- `gospel/PT-Portuguese/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
